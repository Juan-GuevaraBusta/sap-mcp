# PR-001b · Portar la semilla offline de Aprendiz

## Objetivo

El comportamiento offline ya probado de Aprendiz (driver RFB, presupuesto, schemas, redacción, resumen, fechas y tablas) vive en el paquete `sap_mcp` y su suite pasa sin red.

## Contexto

- `docs/roadmap.md`, PR-001.
- `docs/audit-aprendiz.md` §3 y §7.
- Origen: repositorio `JuanMCanchala/frontier-hackathon`, copia local `Developer/personal/hackathons/frontier-hackathon-equipo`, commit `56afa80`.

Este PR asume que PR-001a ya está en `main`: `pyproject.toml`, `src/sap_mcp/__init__.py` y la toolchain `uv` / `pytest` / `ruff`.

## Fuera de alcance

- `tasks.py` y `store.py`. Importan `runner.py`; copiarlos arrastraría el runner HTTP y el episodio monolítico. El supervisor se porta en PR-005.
- `episode.py`, `runner.py`, `api.py`, `gate.py`, `classifier.py`, `detector.py`, `verifier.py`, `planner.py`, `textrule.py` y `eval/`.
- Quitar la resolución fija 1280×800. La quita PR-004.
- Sacar los precios de OpenRouter del código. Lo hace PR-006. Aquí `config.py` y `agent/config.py` se copian tal cual, precios incluidos.
- Crear `src/sap_mcp/interaction/` o `src/sap_mcp/knowledge/`.
- Modificar `pyproject.toml` ni `src/sap_mcp/__init__.py`.

## Contrato

Reescritura mecánica de imports: `aprendiz` pasa a `sap_mcp`. La lógica de cada módulo no cambia. El diff de cada archivo, ignorando las líneas de import, queda vacío respecto al origen.
